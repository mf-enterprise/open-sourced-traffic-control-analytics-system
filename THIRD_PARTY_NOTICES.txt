Topurrra/rtdetr-license-plate-detection-onnx. The exact pinned model card declares

PP-OCRv6-small text-recognition model and dictionary
--------------------------------------------------
public/models/plate-recognizer.onnx is the unchanged official PaddlePaddle
PP-OCRv6_small_rec_onnx artifact. The pinned model card declares Apache License
2.0. The original model card and inference configuration are included. The JSON
dictionary derives from the exact embedded upstream character list, prepending
CTC blank and appending space according to PaddleX's decoder. The resulting
18,710-class vocabulary is separate from the app's Latin registration input guard.

FFmpeg camera gateway
---------------------
The source development setup uses ffmpeg-static 5.3.0, whose package declares
GPL-3.0-or-later and downloads a platform-specific FFmpeg executable during
installation. The inspected Windows executable is FFmpeg 6.1.1,
6.1.1-essentials_build-www.gyan.dev, compiled with --enable-gpl,
--enable-version3, and --enable-libx264; its license output states GPL version 3
or later. The gateway uses libx264. Other platforms or dependency configurations
can select a different build and must be checked separately.

Windows desktop distribution
----------------------------
The Windows ZIP does not contain FFmpeg or ffmpeg-static. On first launch, the
application downloads the pinned upstream FFmpeg executable directly to the
user cache and verifies its SHA-256. The download URL, version, expected hash,
and upstream notices are declared in desktop/runtime.mjs.

Electron and Chromium licenses ship beside the executable. Native dependency
licenses remain in their package folders; desktop packaging also produces an
inventory and copied licenses for bundled browser and backend dependencies.
Public camera streams belong to their providers and are not relicensed under
the application license. The camera directory includes source attribution.
